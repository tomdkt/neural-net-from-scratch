# Neural Network From Scratch

Repository for training and evaluating custom neural network architectures using PyTorch and Scikit-Learn.

## Prerequisites

- Python `>= 3.12`
- [uv](https://github.com/astral-sh/uv) (Fast Python package installer)
- NVIDIA GPU + CUDA Drivers (optional, for acceleration)
